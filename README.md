# Эмулятор работы в командной строке UNIX подобной ОС
## Этап 1: REPL

Минимальный прототип эмулятора командной строки с GUI на tkinter.

### Возможности:
* Графическое окно, заголовок это имя VFS.
* Парсер команд с корректной обработкой кавычек через shlex.
* Команды-заглушки: ls, cd - печатают имя и аргументы.
* Команда exit - закрывает окно.
* Обработка ошибок: неизвестная команда, незакрытые кавычки, пустой ввод.

## Этап 2: Конфигурация

Прототип эмулятора со стартовыми скриптами.

### Возможности:
* Параметры командной строки --vfs и --script через argparse.
* Отладочный вывод всех параметров при запуске.
* Выполнение стартового скрипта с остановкой на первой ошибке.
* Сообщение об ошибке в терминал и диалоговое окно.
* Игнорирование пустых строк и комментариев в скрипте.
* Скрипты реальной ОС (run.bat, run.sh, Makefile) для тестирования параметров.

## Этап 3: VFS

Прототип с VFS на базе JSON-файла.

### Возможности:
* VFS хранится в памяти, источник - JSON-файл.
* Двоичные данные поддерживаются через base64.
* Команда vfs-init сбрасывает VFS к default и очищает файл.
* Загрузка VFS при старте с отладочным выводом.
* Обработка ошибок: нет файла VFS или битый JSON-файл.
